# 波段扫描器（过渡版）

在美股接入主程序之前，用这组独立脚本每天扫描一次信号，结果写进 claude.ai 上的「波段扫描器」看板。等主程序的美股选股、回测和推送完成后，这个目录会被替换。

## 规则

- 股票池：纳指 100 成分股（`universe_ndx.txt`）+ 自选股（`watchlist.txt`，每行一个代码，可选）
- 趋势：收盘价在 200 日均线上方，且 50 日均线在 200 日均线上方
- 入场：前一天收在 20 日均线下方，今天重新站上 20 日均线并高于 50 日均线；次日开盘买入
- 仓位：单笔风险 $1,500（总资金 30 万 × 0.5%），股数 = 1,500 ÷ (2 × ATR14)；单只上限为波段资金 21 万的 30%；最多 10 只
- 加仓：每上涨 2 ATR 加一次，最多两次；第一次加仓后止损上移到首笔买入价
- 出场：止损 = max(初始止损, 持仓以来最高收盘 − 3 ATR)，盘中跌破即卖出

## 运行

```bash
bash tools/swing-scanner/run.sh            # 输出到 tools/swing-scanner/out/
```

依赖：Python 3.11+、pandas、numpy、curl。数据来自 Yahoo Finance 公开日线接口。

## 文件

| 文件 | 作用 |
| --- | --- |
| `swing_engine.py` | 组合级回测引擎与指标 |
| `swing_compare.py` | 回调/突破 × 不加仓/顺势加仓/回调加仓 × 大盘过滤，共 12 个版本对比 |
| `swing_scan.py` | 用选定规则生成今日信号、规则持仓、观察名单 |
| `build_datasets.py` | 整理成看板读取的 JSON 数据文件，含稳健性检查 |

## 已知局限

股票池使用当前成分股，存在幸存者偏差；剔除近年新进的高涨幅股票后，回测收益大幅下降。结果只用于计算仓位和止损，不构成买入建议。
